# html-trial

A collection of beginner HTML & CSS practice projects and exercises, built while learning front-end web development fundamentals. Each project explores a different concept — from basic page structure to the three ways of writing CSS.

## 🔗 Getting Started

No build tools or dependencies are required.

1. Clone or download this repository
2. Open `index.html` in any web browser
3. Use the links on the home page to navigate to each individual project

```
git clone https://github.com/<your-username>/html-trial.git
cd html-trial
open index.html   # or just double-click the file
```

## 📁 Project Structure

```
html-trial/
├── index.html              # Portfolio home page linking to every project
├── assets/
│   └── images/              # Images used across the projects
└── public/
    ├── about.html            # About Me / profile page
    ├── contact.html           # Contact details page
    ├── movie-ranking.html     # Top 3 favorite movies
    ├── birthday-invite.html   # Birthday party invitation page
    ├── meme.html              # "Motivation MEME" styling exercise
    ├── color.html             # Spanish color vocabulary exercise
    ├── css.html               # Hub page linking the 3 ways to add CSS
    ├── inline.html            # Inline CSS example
    ├── int.html               # Internal (`<style>` tag) CSS example

```

## 🗂️ Included Projects

| Project | Description |
|---|---|
| **Portfolio Home** | Landing page with a short intro and links to every project below |
| **Movie Ranking** | A simple list ranking top 3 all-time favorite movies |
| **Birthday Invite** | A styled invitation page with event details and a map link |
| **Methods to Add CSS** | Demonstrates the three ways to apply CSS — inline, internal, and external — each on its own page |
| **Motivation MEME** | A styling exercise recreating a meme layout using Google Fonts and custom CSS (`text-transform`, centering, borders) |
| **Spanish Colors** | An exercise in using an external stylesheet and element IDs to style a vocabulary page |
| **About Me** | A short profile with education and interests |
| **Contact Me** | Basic contact information page |

## 🛠️ Concepts Practiced

- Semantic HTML structure (`h1`–`h3`, lists, links, images, `<hr>`)
- The three methods of adding CSS: **inline**, **internal**, and **external**
- Linking a shared external stylesheet (`style.css`) across multiple pages
- Using CSS selectors, IDs, and properties like `text-transform`, `font-weight`, `width`/`height`
- Importing and applying custom Google Fonts
- Relative file paths for linking between pages, images, and stylesheets within a project
